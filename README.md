# 롤 내전 밸런스 메이커 🛡️

리그 오브 레전드 내전(인하우스)을 위한 **팀 밸런스 메이커**입니다.
선수 명단을 한 번 등록해두면, 그날 모인 **10명만 체크**해서 점수가 비슷한 5:5 팀을 자동으로 짜줍니다.

라이엇 클라이언트의 헥스테크 무드(딥네이비 + 골드)와 챔피언 선택 화면 느낌의 결과 화면을 의도했습니다.

---

## ✨ 주요 기능

- **선수 명단 관리** — 닉네임 + 주 라인(티어/단계) + 부 라인(티어/단계)을 등록·수정·삭제. 한 번 등록하면 브라우저에 저장됩니다.
- **주/부 라인 점수 분리** — 예: 주라인 골드 / 부라인 실버처럼 라인마다 다른 티어를 입력하고, 배치된 라인에 맞는 점수로 계산합니다.
- **5:5 밸런스 메이커** — 10명을 체크하면, 모두 주/부 라인에 배치하면서(불가피할 때만 자동배치) **양 팀 총점 차이가 최소가 되는 조합**을 찾아줍니다.
- **다시 섞기** — 비슷한 수준의 다른 조합을 다시 뽑을 수 있습니다.
- **데이터 백업/불러오기** — 명단을 JSON으로 복사해두거나 다른 기기로 옮길 수 있습니다.

---

## 🧮 점수 / 밸런스 방식

- 티어를 점수로 환산하며, 윗 티어로 갈수록 점수 간격이 벌어지도록 설계해 실제 실력차를 반영합니다 (아이언 ~ 챌린저).
- 밸런스 알고리즘은 두 조건을 우선순위대로 맞춥니다.
  1. 가능한 한 모든 선수를 **주/부 라인에 배치** (불가피할 때만 자동배치)
  2. **양 팀 총점 차이 최소화** — 포지션별 2명을 블루/레드로 가르는 모든 경우의 수를 비교
- 결과 하단에 점수 차이, 블루/레드 총점, 밸런스 등급이 표시됩니다.

## 🚀 로컬에서 실행하기 (VSCode)

별도 빌드 과정이 없는 순수 정적 사이트입니다.

**가장 쉬운 방법**: `index.html` 파일을 더블클릭해서 브라우저로 열기

**VSCode + Live Server 추천**
1. VSCode 확장 마켓에서 **Live Server** 설치
2. `index.html`을 우클릭 → **Open with Live Server**
3. 코드를 저장하면 자동으로 새로고침됩니다.

## 🌐 GitHub에 올리고 Pages로 배포하기

### 1) 깃허브에 올리기

```bash
git init
git add .
git commit -m "롤 내전 밸런스 메이커"
git branch -M main
git remote add origin https://github.com/<본인아이디>/<저장소이름>.git
git push -u origin main
```

### 2) GitHub Pages 켜기

1. 깃허브 저장소 → **Settings** → 좌측 **Pages**
2. **Source**를 `Deploy from a branch`로 두고, Branch를 `main` / `/(root)`로 선택 후 저장
3. 잠시 뒤 `https://<본인아이디>.github.io/<저장소이름>/` 주소로 접속하면 됩니다.

## 💾 데이터 저장 안내

명단은 `localStorage`를 사용해 **접속한 브라우저에 저장**됩니다.
- 같은 브라우저에서는 새로고침해도 유지됩니다.
- 다른 기기/브라우저로 옮기려면 앱 안의 **데이터 백업 / 불러오기** 기능을 사용하세요.
- 시크릿(사생활 보호) 모드에서는 저장이 안 될 수 있습니다.
